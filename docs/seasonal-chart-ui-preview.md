# Seasonal chart UI preview

Plant info displays a compact annual chart with a Learn more action. The detail sheet places a larger graph first, followed by placeholder sections for seasonal patterns, location, growing setup and guidance.

This is an explicitly labelled design preview. The curve is a static illustration without numeric watering intervals. It does not use journal entries, location-derived seasonal calculations or the care algorithm. No stored care records or reminder behavior changed.

Verified with component/navigation tests, type checking, lint and a browser layout review.
